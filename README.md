# Generative AI From Scratch

A hands-on learning repository for understanding **Generative AI by building the core models from scratch with PyTorch**.

The main goal of this repository is not to use ready-made implementations, but to understand the **ideas, mathematics, architecture, and code** behind generative models.

---

## 📚 Learning Path

The repository is organized as a gradual progression:

```text
Autoencoder
    ↓
Variational Autoencoder
    ↓
GAN
    ↓
More advanced Generative AI
```

Each topic is studied in two different ways:

```text
Educational
    ↓
Understand the concepts
    ↓
Understand the mathematics
    ↓
Study a clean implementation

From-Scratch
    ↓
Rebuild the idea yourself
    ↓
Experiment
    ↓
Write the code manually
```

Each notebook focuses on:

* architecture,

## 🛠️ From Scratch

This section is the practical part of the repository.

The goal is to take what was learned in the educational notebooks and **rebuild it independently**.

```text

More thinking

```

The implementations may start simple and gradually become more advanced.

## 🔬 Philosophy

This repository follows a simple rule:

> **Don't just run the model. Understand why the model works.**

For important concepts, the learning process is:

```text
Concept
   ↓
Intuition
   ↓
Mathematics
   ↓
Implementation
   ↓
Visualization
   ↓
Experiment
   ↓
Understanding
```
